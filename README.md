# Towards Complete Molecular Structure Prediction from Infrared Spectroscopy

This repository provides a deep learning framework for predicting molecular structures using infrared (IR) spectroscopy data.

## Repository Structure
- `utils/`: Utility scripts for data processing and model architecture.
- `train.ipynb`: Main notebook for training models and performing inference.
- `results/`:
  - `models/`: Stores trained models, embeddings, and outputs.
  - `analysis/`: Scripts and notebooks for analyzing results and generating visualizations.

## Installation
Clone the repository and then install the required dependencies:

```bash
pip install -r requirements.txt
```
